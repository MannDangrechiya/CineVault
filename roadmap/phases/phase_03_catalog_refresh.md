# Phase 3 — Catalog Refresh / Update System
**Goal:** Controlled metadata refresh.

## Support
changed metadata, new aliases, new releases, changed availability, corrected
runtime, changed credits, provider updates.

## Must preserve
personal ratings, watch history, notes, favorites, progress, reviews, collections.

## Implement
change detection → provenance → conflict creation → reconciliation → review → canonical promotion

No silent overwrite of verified data.
