# Phase 11 — Taste Profile
**Goal:** Build a user taste model.

## Analyze
genres, themes, countries, languages, decades, directors, actors, studios,
franchises, runtime preferences, rating behavior, completion behavior, watch frequency.

## The system should learn
what the user likes, avoids, finishes, and abandons.

## Constraint
Do not infer sensitive personal attributes. Do not create invasive profiling.
