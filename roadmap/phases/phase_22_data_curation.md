# Phase 22 — Data Curation
**Goal:** Build the real global catalog systematically.

## Prioritize
major cinema, Indian cinema, Korean, Japanese, Chinese, anime, Hollywood,
European cinema, international TV/web, documentaries.

## Constraint
Coverage must not become uncontrolled row inflation. Priority order:
Accuracy, Provenance, Deduplication, Consistency, Coverage — before quantity.
Community ratings must remain labeled as community data.
