# Phase 5 — Personal User Foundation
**Goal:** Build the complete personal media layer.

## Implement
watchlist, watched, watching, completed, dropped, planned, favorites, ratings,
reviews, notes, personal status, movie progress, episode progress, rewatch history.

## Constraint
Every record must belong to the authenticated user.

## Test
User A must never see or modify User B's data.
Personal data stays separate from canonical metadata.
